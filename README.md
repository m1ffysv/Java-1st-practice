Работа с матрицами комплексных чисел

Программа на Java для выполнения основных операций с матрицами комплексных чисел.

Возможности программы:

-Сложение матриц

-Умножение матриц

-Деление матриц

-Транспонирование матрицы

-Вычисление определителя

-Нахождение обратной матрицы

Файлы проекта:

Complex.java — работа с комплексными числами

Matrix.java — работа с матрицами

Main.java — консольное меню программы
